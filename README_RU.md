# Lectura — Умная система чтения и изучения языков с ИИ

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Docker](https://img.shields.io/badge/Docker-Ready-2496ED?logo=docker&logoColor=white)](docker-compose.prod.yml)
[![Version](https://img.shields.io/badge/version-1.0.1-green.svg)](https://github.com/rustams1990/Lectura/releases)

Добро пожаловать в **Lectura**! Это современное приложение с открытым исходным кодом для чтения книг, статей и просмотра видео на иностранных языках с мгновенным контекстным переводом, качественной озвучкой, разбором грамматики и автоматическим формированием личного словаря на базе искусственного интеллекта Google Gemini или локальных моделей (Ollama).

---

## 💡 Основные возможности системы

* 📖 **Интерактивное чтение книг и статей:**
  * Кликните на любое незнакомое слово в тексте, чтобы мгновенно получить контекстный перевод от ИИ.
  * Транскрипция в международном фонетическом алфавите (IPA).
  * Грамматический разбор (часть речи, род, форма, базовый корень).
  * Примеры употребления в предложениях с переводом.
  * Выделение фраз, идиом и фразовых глаголов с помощью мыши или Shift+клик.
* 📥 **Импорт материалов:**
  * Поддержка **PDF, EPUB, TXT**.
  * Парсер веб-страниц по URL (очищает статью от баннеров и рекламы для комфортного чтения).
* 🎬 **Интерактивный YouTube-плеер:**
  * Вставьте ссылку на любое видео. Lectura извлечёт субтитры (или сгенерирует их через ИИ), превратит в интерактивный синхронный текст и позволит разбирать речь носителей в реальном времени.
* 🧠 **Личный словарь и интервальное повторение (SRS):**
  * Слова распределяются по уровням освоения (Новое, Изучается, Знакомо, Известно).
  * Умная лемматизация и морфология: система объединяет разные словоформы с базовым словом, исключая дубликаты.
  * Режимы тренировок: флэш-карточки, проверка правописания, аудирование.
* 🔒 **Полная автономность и приватность:**
  * Все ваши данные хранятся локально в базе данных SQLite.
  * Поддержка полностью офлайн-режима: можно подключить локальную нейросеть через **Ollama** и локальную озвучку **Kokoro-82M TTS**.

## 🚀 Варианты запуска и установки

### Способ 1. Быстрый запуск на Windows в 1 клик (Без Docker — Рекомендуется)
Самый лёгкий способ запустить проект на домашнем компьютере с Windows:

1. Установите:
   * **[Node.js](https://nodejs.org/)** (версия 20 или новее LTS).
   * **[Python 3](https://www.python.org/downloads/)** (требуется библиотеке `yt-dlp` для извлечения видео и субтитров с YouTube).
     > ⚠️ **Важно:** при установке Python обязательно отметьте галочку **"Add python.exe to PATH"** в первом окне установщика!
2. Скачайте архив с релизом (или клонируйте репозиторий) и дважды кликните по файлу **`run.bat`**.
   * Скрипт сам проверит окружение, установит зависимости (`npm install`), создаст конфигурацию `.env` и поднимет сервер.
3. Откройте браузер: **[http://localhost:3000](http://localhost:3000)**.
4. В приложении нажмите иконку шестерёнки (**Настройки**) и вставьте ваш бесплатный ключ **Google Gemini API**.

#### 🔄 Как обновлять приложение на Windows:
Все ваши книги, словарь, заметки и настройки хранятся в файле **`local_server_db.sqlite`** (а API-ключи — в **`.env`**). При обновлениях эти файлы не перезаписываются:
* **Автоматически в 1 клик:** просто дважды кликните **`update.bat`**. Скрипт сделает резервную копию базы данных в `./backups/`, загрузит свежие файлы и обновит зависимости.
* **Вручную (при скачивании нового ZIP релиза):** распакуйте новый архив и перенесите из старой папки два файла — `local_server_db.sqlite` и `.env`. Затем запустите `run.bat`.

### Способ 2. Запуск через Docker (Опционально)
Запуск в изолированном контейнере без необходимости ставить Node.js и Python на хост-систему.

1. Убедитесь, что установлен и запущен [Docker Desktop](https://www.docker.com/products/docker-desktop/).
   * *Для Windows:* можно скачать `.exe` с официального сайта или выполнить в консоли:
     ```cmd
     winget install --id Docker.DockerDesktop --source winget
     ```
2. Склонируйте репозиторий (или скачайте исходный код):
   ```bash
   git clone https://github.com/rustams1990/Lectura.git
   cd Lectura
   ```
3. Запустите контейнер:
   ```bash
   docker compose -f docker-compose.prod.yml up -d
   ```
4. Откройте в браузере: **[http://localhost:8586](http://localhost:8586)**.
5. Перейдите в **Настройки (Settings)** внутри Lectura и укажите ваш бесплатный ключ **Google Gemini API**.

---

### Способ 3. Для разработчиков (Terminal: Windows, macOS, Linux)

1. Убедитесь, что установлены **Node.js 20+** и **Python 3**.
2. Установите зависимости:
   ```bash
   git clone https://github.com/rustams1990/Lectura.git
   cd Lectura
   npm install
   ```
   *(Если Python не установлен, можно выполнить `npm install --ignore-scripts`, но функционал скачивания YouTube-видео потребует наличия Python)*.
3. Создайте файл `.env`:
   ```bash
   cp .env.example .env
   ```
4. Запустите в режиме разработки (с горячей перезагрузкой):
   ```bash
   npm run dev
   ```
5. Приложение доступно по адресу: **`http://localhost:3000`**.

---

### Способ 4. Установка на Ubuntu Server (Production)

1. Установите Docker:
   ```bash
   sudo apt update && sudo apt install -y docker.io docker-compose-v2
   sudo systemctl enable --now docker
   ```
2. Клонируйте репозиторий и поднимите контейнер:
   ```bash
   git clone https://github.com/rustams1990/Lectura.git
   cd Lectura
   docker compose -f docker-compose.prod.yml up -d
   ```
3. Приложение работает на порту `8586`.
4. **Обновление сервера**: для быстрого и безопасного обновления используйте встроенный скрипт:
   ```bash
   ./scripts/update-server.sh
   ```
   *Скрипт автоматически сделает резервную копию базы данных SQLite в папку `./backups`, скачает свежий Docker-образ и перезапустит сервис за 15 секунд.*

## 🔑 Настройка ИИ и API-ключей

### Google Gemini API (Облачный режим)
* Получите бесплатный ключ в [Google AI Studio](https://aistudio.google.com/).
* Вставьте его прямо в **Настройках** внутри приложения Lectura (ключ сохранится в вашем профиле).

### Ollama (Локальный офлайн режим)
* Установите [Ollama](https://ollama.com/) на ПК или сервер.
* Запустите модель (например, `ollama run qwen2.5:3b` или `llama3`).
* В настройках Lectura переключите **AI Provider** на **Local (Ollama)**.
